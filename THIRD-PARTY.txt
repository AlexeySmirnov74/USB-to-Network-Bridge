USBBridge applications and USB/IP implementation are new Rust code, MIT.
The offline binary package includes applications, scripts, dependency
licenses and the unchanged, signed upstream driver installers listed below.
No third-party kernel binary is modified.

PRODUCTION DRIVER DEPENDENCIES (included offline installers)

usbipd-win 5.3.0, GPL-3.0-only
  https://github.com/dorssel/usbipd-win/releases/tag/v5.3.0
  https://github.com/dorssel/usbipd-win/tree/v5.3.0
  Installs VirtualBox 7.2.2 VBoxUSB/VBoxUSBMon production drivers.
  Upstream driver licensing and source notices:
  https://github.com/dorssel/usbipd-win/tree/v5.3.0/Drivers
  Corresponding VirtualBox source: https://download.virtualbox.org/virtualbox/7.2.2/VirtualBox-7.2.2.tar.bz2

USBIP-WIN2 0.9.8.1, BSD-2-Clause
  https://github.com/vadimgrn/usbip-win2/releases/tag/v.0.9.8.1
  https://github.com/vadimgrn/usbip-win2/blob/v.0.9.8.1/LICENSE.txt
  Provides the virtual host controller and its companion filter driver.
  These are used unchanged. The Rust client calls their public control ABI;
  the driver's WSK transport handles USB payloads in the Windows kernel.

Full upstream license texts and driver notices are in licenses/drivers/.
The matching GitHub release provides a separate driver-sources archive with
the pinned usbipd-win and VirtualBox corresponding source. See
docs/driver-sources.md for the exact versions and original source locations.
USBIP-WIN2's source is also provided for reproducibility.

UNITY CAPTURE DIRECTSHOW FILTER (included offline)

Unity Capture x64 filter, MIT, Copyright (c) 2018 Bernhard Schelling;
based on UnityCam, Copyright (c) 2016 MHD Yamen Saraiji.
  https://github.com/schellingb/UnityCapture
  Exact upstream commit and SHA-256: unity-capture.json
  Unmodified userspace DLL: components/unity-capture/UnityCaptureFilter64.dll
  Full notice and source location: licenses/unity-capture/
The separate Unity producer plugin/assets (zlib) are not included. OBS and
producer applications must be installed/configured separately if used.

The USBIP-WIN2 installer embeds the Microsoft Visual C++ Redistributable.
It remains inside the unchanged upstream installer and retains its original
Microsoft terms. Our Rust EXEs use the static CRT and do not require a
separate .NET or Visual C++ runtime installation.

The public ioctl constants and structure layouts implemented by src/vbox.rs
follow the VirtualBox usblib-win.h ABI. No usbipd-win C# implementation is
compiled into or distributed with the Rust applications.

OPTIONAL RESEARCH BACKEND

src/usbdk.rs implements an optional UsbDk C API adapter. The default
production setup does not download, install or bundle UsbDk.
Upstream: https://github.com/daynix/UsbDk (Apache-2.0).

Local vendor snapshots and earlier test-signed driver experiments remain
outside the Git index and source/release packages. If distributing those
separately, preserve their upstream licence and copyright notices and
provide the corresponding source and modifications as applicable.
