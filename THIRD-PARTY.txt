PRODUCTION DRIVER DEPENDENCIES (separate upstream downloads)

usbipd-win 5.3.0, GPL-3.0-only
  https://github.com/dorssel/usbipd-win/releases/tag/v5.3.0
  https://github.com/dorssel/usbipd-win/tree/v5.3.0
  Installs VirtualBox 7.2.2 VBoxUSB/VBoxUSBMon production drivers.
  Upstream driver licensing and source notices:
  https://github.com/dorssel/usbipd-win/tree/v5.3.0/Drivers
  VirtualBox source releases: https://download.virtualbox.org/virtualbox/

USBIP-WIN2 0.9.8.1, BSD-2-Clause
  https://github.com/vadimgrn/usbip-win2/releases/tag/v.0.9.8.1
  https://github.com/vadimgrn/usbip-win2/blob/v.0.9.8.1/LICENSE.txt
  Provides the virtual host controller and its companion filter driver.
  These are used unchanged. The Rust client calls their public control ABI;
  the driver's WSK transport handles USB payloads in the Windows kernel.

The public ioctl constants and structure layouts implemented by src/vbox.rs
follow the VirtualBox usblib-win.h ABI. No usbipd-win C# implementation is
compiled into or distributed with the Rust applications.

OPTIONAL RESEARCH BACKEND

src/usbdk.rs implements an optional UsbDk C API adapter. The default
production setup does not download, install or bundle UsbDk.
Upstream: https://github.com/daynix/UsbDk (Apache-2.0).

Local vendor snapshots and earlier test-signed driver experiments remain
outside the Git index and source/release packages. If distributing those
separately, preserve their upstream licence and copyright notices and
provide the corresponding source and modifications as applicable.
